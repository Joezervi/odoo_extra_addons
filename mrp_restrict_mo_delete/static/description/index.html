Mrp Restrict MO Delete

Description

This module is used to restrict the delete option for Manufacturing Order by hiding the Delete button in the MO through a group.

Configuration

After installing the Restrict MO Delete application, the feature will be enabled.

This app hides the delete option from the Manufacturing Order by disabling “ Can Delete MO ” from Users.

Go to Settings - - > Users & Companies - - > Users.

Click on the Admin user where the “ Can Delete MO ” boolean group is added under the access rights of the user.

Functionality

Go to Manufacturing - - > Operations - - > Manufacturing Orders.

When the “ Can Delete MO ” option is disabled in Users, the delete option will be hidden from the form view and tree view.

Select the MO and then click on Action Button where the delete option will be hidden in the tree view and form view.

If you enable the “ Can Delete MO ” boolean, the delete option will be visible in the MO tree view and form view.
