Manufacturing Delay Alerts

Managing a factory is not easy — especially when delays happen or one shift has too much work.
This module helps you keep everything under control:
It tracks late Manufacturing Orders (MOs) and shows exactly how many days they are delayed.
It lets you assign orders to specific shifts (Shift A, B, or C).
It warns you automatically when a shift is overloaded with too many open orders.
It updates shift loads in real time so you always have the latest information.
With this module, production managers can quickly react to delays, balance workloads, and keep production on track.


How It Works
When you create or update a Manufacturing Order, you can select Shift A, B, or C.
The system calculates the delay (in days) if the order is finished after the deadline.
Alerts are sent if the order is delayed or if a shift has too many open orders.
Managers can check the workload per shift and adjust schedules accordingly.
