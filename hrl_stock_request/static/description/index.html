Inter-Warehouse Stock Request

Submit a single Stock Request and let the system do the rest — automatically creating a Delivery from the source warehouse to transit, and a Receipt from transit to the destination warehouse. Full traceability, zero manual effort.

1

Create & Confirm Stock Request

Navigate to Operations > Stock Request, fill in the source warehouse, destination location, and products — then hit Confirm.

2

Auto-Generated Two-Step Transfers via Transit

Upon confirmation, the system instantly generates two linked transfers — a Delivery (Source → Virtual Locations/Transit) and a Receipt (Transit → Destination), both traceable back to the original SR/ reference number.

Two-Step Transfer via Transit Location

Every confirmed Stock Request automatically triggers two traceable internal transfers — stock moves through a Virtual Transit Location before reaching the destination warehouse, ensuring clean inventory records at every stage.

1

Delivery — Source to Transit

Operation type YourCompany: Internal Transfers moves stock from WH/Stock → Virtual Locations/Transit.

2

Receipt — Transit to Destination

Operation type New Warehouse: Internal Transfers receives stock from Virtual Locations/Transit → NW/Stock.

One-Form Stock Request

Submit a complete inter-warehouse transfer request from a single form — define source warehouse, destination location, products, and quantities all in one place. No multi-step setup required.

Auto Two-Step Transfer Generation

On confirmation, the system automatically generates both a Delivery (Source → Transit) and a Receipt (Transit → Destination) — zero manual transfer creation, zero room for error.

Transit Location Routing

Stock is routed through Virtual Locations/Transit between warehouses — keeping inventory records accurate and compliant at every movement stage, with no ghost stock in either location.

Smart Buttons for Instant Navigation

Delivery and Receipt smart buttons appear directly on the Stock Request form — jump to any linked transfer in one click and monitor progress without leaving the record.

Full Traceability via Source Document

Every auto-generated transfer carries the originating SR/ reference as its Source Document — giving your team and auditors a clear, end-to-end trail from request to final receipt.

Draft → Confirm → Validate Workflow

A clean three-stage approval workflow keeps every request controlled and auditable — from initial Draft submission through Confirm all the way to final Validate, with full status visibility at every step.
